# Испытания тренера на собственной модели

Это стенд проверки. Он не меняет провайдер рабочего сайта и не запускает Hermes
для клиентов. Команды генерации требуют уже доступного собственного GPU-сервера.
Стоимость нового сервера должна быть отдельно согласована.

## Подготовка без генерации

Из корня репозитория, в Python-окружении с `services/video/requirements.txt`:

```bash
mkdir -p evals/open_coach/runs
python scripts/evaluate-open-coach.py \
  --model Qwen/Qwen3.6-27B-FP8 \
  --model-revision e89b16ebf1988b3d6befa7de50abc2d76f26eb09 \
  --output evals/open_coach/runs/qwen27b-preflight.json
```

Без `--run` сетевых запросов нет. Выход содержит подготовленные запросы,
контрольные суммы промпта, схемы и фактов, отдельные критерии для проверяющего.
Файл с тем же именем не перезаписывается. `runs/` и `private/` исключены из Git;
не публикуйте экспорт реального игрока или сгенерированные частные отчёты.

## Запуск модели после получения GPU

Для основного кандидата используйте закреплённую ревизию из `candidates.json`.
Автор модели рекомендует [vLLM не ниже 0.19.0](https://huggingface.co/Qwen/Qwen3.6-27B-FP8).
Следующая команда — начальная конфигурация испытания, **на GPU ещё не выполнена**.
Запишите фактические версии vLLM, PyTorch, CUDA, драйвера и модель видеокарты
рядом с отчётом. Пакеты устанавливаются в отдельное окружение GPU, не в сервер Narma.

```bash
vllm serve Qwen/Qwen3.6-27B-FP8 \
  --revision e89b16ebf1988b3d6befa7de50abc2d76f26eb09 \
  --host 127.0.0.1 --port 8000 \
  --tensor-parallel-size 1 --max-num-seqs 1 \
  --max-model-len 16384 --gpu-memory-utilization 0.85 \
  --reasoning-parser qwen3 --language-model-only
```

Сервер слушает только loopback. Для удалённого GPU настройте проверенный
SSH-туннель к этому порту; публичный доступ к генерации не открывайте.
Стенд принимает только `localhost`, `127.0.0.1` или `::1` и точный маршрут
`/v1/chat/completions`. Внешние ключи и токены ChatGPT не используются.
Инструменты отключены, вызовы последовательны, автоматических повторов нет.

```bash
python scripts/evaluate-open-coach.py \
  --model Qwen/Qwen3.6-27B-FP8 \
  --model-revision e89b16ebf1988b3d6befa7de50abc2d76f26eb09 \
  --max-tokens 8192 --timeout 300 \
  --output evals/open_coach/runs/qwen27b-synthetic.json \
  --run
```

Перед сравнением также запишите ревизию модели из `candidates.json` в протокол
развёртывания. Имя модели, возвращённое HTTP-сервером, само по себе не подтверждает
ревизию весов. Reasoning потребляет часть лимита ответа; обрезанный ответ считается
незавершённым. Транспортная или ресурсная ошибка не является оценкой знаний Dota.
Не увеличивайте контекст или параллельность автоматически после нехватки памяти.

## Реальные эпизоды и сравнение

Синтетический набор — предварительная проверка. Для реальных данных сохраните
разрешённый корпус в `evals/open_coach/private/` с той же структурой кейсов и
`classification: "private_real_replay_evidence"`. Передайте его через
`--cases`. Каждый кейс содержит только разрешённый фактический отчёт выбранного
игрока, его позицию и настройки обучения. Персональные заметки и ожидаемые
ответы остаются вне модельного запроса.

Нужны 30–50 реальных эпизодов всех пяти позиций, отдельные наборы для настройки
и контрольной проверки. Сравнивайте ответы кандидатов на одинаковых входах
по `RUBRIC.md`, скрыв названия моделей от проверяющих. Для вывода о небольшом
снижении относительно ChatGPT необходим сравнимый проверенный эталон ChatGPT;
успешная проверка синтетического JSON такого вывода не позволяет.

После каждой попытки сохраняется результат. Даже если все структурные проверки
успешны, `quality_status` остаётся `not_evaluated` до отдельной человеческой оценки.
Допуск модели, обслуживание нескольких клиентов и включение Hermes являются
следующим этапом после оценки качества и измерения ресурсов.

## Ограниченный первый GPU-прогон

Предлагаемый объём: один GPU 48 GB, до четырёх часов суммарно, последовательная
проверка двух кандидатов, без переключения клиентского сайта. Новый расход пока
не разрешён. Вычисления по проверенным публичным ставкам оценены в
`docs/OPEN_COACH_EVALUATION.md`; итоговую конфигурацию и цену нужно подтвердить
до создания ресурса. Изменение размера GPU или продолжение после лимита требует
нового решения, а не автоматического расширения.

Сохраните результаты до удаления тестового ресурса. Остановка модели или Pod
не обязательно прекращает оплату диска; после завершения нужно проверить
отсутствие оставшихся платных ресурсов. Этот пакет не создаёт и не удаляет их.
