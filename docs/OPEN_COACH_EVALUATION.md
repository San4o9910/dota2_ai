# Открытая модель для Narma: допуск по качеству

Дата исследования: 2026-09-11. База кода: `6ae85abde39a6774044107433551204241d563b3`.
Статус: выполнена локальная CPU-проба компактного Qwen; модель не подключена
клиентам. Результаты и ограничения: [протокол пробы](QWEN_CPU_TRIAL_2026-09-11.md).

## Решение владельца

ИИ нужен всем клиентам Narma. Использование чужих подписок не требуется.
Владелец разрешил заменить ChatGPT открытой моделью при небольшом снижении качества.
Это разрешает подготовку и проверку интеграции; новый платный GPU и увеличение
бюджета пока не согласованы. Личная Pro 5× не используется как общий провайдер.

## Что можно проверить сейчас

`scripts/evaluate-open-coach.py` использует действующие подготовку фактов,
тренерскую инструкцию, JSON-контракт и проверку ссылок на события из
`narma_video.replay_coach`. Без явного запуска генерации он готовит пакет
испытаний. Генерация разрешена только через локальный адрес собственного сервера
модели; удалённый GPU подключается через SSH-туннель. Платные внешние провайдеры,
подписочные токены, запасные модели и инструменты агента не задействуются.

В `evals/open_coach/cases.json` находятся исходные **синтетические** контрольные
ситуации, а не данные реальных игроков. Они проверяют различия ролей, недостаток
данных, пассивные предметы, неоднозначную причинность и инструкции внутри данных.
Ожидаемые выводы предназначены проверяющему и не отправляются модели.

В рабочем каталоге не найден готовый набор реальных отчётов для сравнения.
Следующий набор нужно собрать из разрешённых экспортов фактических разборов
Narma. Личные отчёты и результаты генерации не добавляются в публичный GitHub.
Прохождение проверок формата не доказывает качество тренера.

## Кандидаты

По запросу владельца первым проверяется компактный
[Qwen3.5-4B Q4_K_M](https://huggingface.co/unsloth/Qwen3.5-4B-GGUF).
GPU не является обязательным условием запуска открытой модели. Прежняя оценка
48 GB ниже относится только к большим FP8-кандидатам. Она не описывает требования
всего семейства Qwen. Процедура CPU-пробы добавлена в
[`evals/open_coach/README.md`](../evals/open_coach/README.md).

| Кандидат | Причина включения | Ограничение |
| --- | --- | --- |
| [Qwen3.6-27B-FP8](https://huggingface.co/Qwen/Qwen3.6-27B-FP8) | Основной кандидат с открытыми весами, лицензией Apache 2.0; плотная модель для проверки подробного разбора | Нет проверенного сравнения с ChatGPT на русских разборах Dota |
| [Qwen3.6-35B-A3B-FP8](https://huggingface.co/Qwen/Qwen3.6-35B-A3B-FP8) | Второй кандидат для проверки скорости и качества; Apache 2.0 | Активные параметры не равны памяти: хранить нужно всю модель |
| [gpt-oss-20b](https://huggingface.co/openai/gpt-oss-20b) | Компактный текстовый контрольный кандидат, Apache 2.0; автор указывает работу в 16 GB памяти | Понимание русского и Dota требует отдельной проверки; нужен совместимый формат Harmony |

Для первых двух кандидатов 48 GB VRAM — отправная конфигурация испытаний,
**инженерная оценка, не измеренный минимум**. FP8-веса, KV-кэш, служебная память,
длина контекста и одновременные запросы должны быть измерены на выбранном движке.
Ревизии весов зафиксированы в `evals/open_coach/candidates.json` по публичному
API автора; веса этих трёх больших моделей не скачивались. Компактная 4B-модель
скачана отдельно, её файл проверен по SHA-256 издателя GGUF.
Агрессивное Q4-квантование считается отдельным кандидатом и проходит весь допуск.
Рекламные и общие модельные бенчмарки не заменяют проверку тренерских советов.

## Инфраструктура и расходы

Последняя опубликованная конфигурация Timeweb VM 9037783 — 4 vCPU, 8 GiB RAM,
80 GiB диска, без GPU; здесь уже работают приложение, PostgreSQL и обработчики
реплеев. Это запись инфраструктуры, а не новое измерение свободной памяти на VPS.
Проверенная рабочая среда разработки имеет лимит 20 GiB памяти и не предоставляет
`nvidia-smi`; GPU для испытания в ней не подтверждён. В ней запущен компактный
Qwen3.5-4B на четырёх CPU-потоках, с одним запросом за раз. Эти измерения не
переносятся автоматически на VPS: процессор и нагрузка другие. Компактная модель
не объявляется равноценной заменой ChatGPT по одному факту успешного запуска.

Без оплаты токенов остаются расходы на собственные вычисления. По публичному
[прайсу Runpod](https://www.runpod.io/pricing), проверенному 2026-09-11,
RTX 6000 Ada 48 GB указан по $0.84/час, L40S 48 GB — $1.09/час.
Четыре часа вычислений составляют соответственно $3.36 и $4.36; это арифметика
прайса, **не окончательная смета**: диск, налоги, доступность региона, время
загрузки и минимальное пополнение проверяются перед заказом. Постоянные 720 часов
по этим ставкам — $604.80 и $784.80 только за вычисления. При небольшом числе
клиентов собственный постоянно работающий GPU может оказаться дороже API.
[Условия расчётов Runpod](https://docs.runpod.io/accounts-billing/billing)
указывают начальное пополнение от $10 и отсутствие возврата внесённых кредитов.
Предлагаемый предел отдельного пробного запуска — $10, до четырёх часов,
без автоматического пополнения; он пока не одобрен владельцем.

В [Timeweb](https://timeweb.cloud/services/gpu) есть GPU 48 GB, но опубликованная
страница предлагает согласование конфигурации и авансовый платёж от 5000 рублей;
подтверждённой почасовой цены выбранного GPU в этой проверке нет. Серверы не
заказывались, заявки и сообщения провайдерам не отправлялись.

## Как сохранить практическое качество

1. Передавать выбранного героя, подтверждённую позицию, эпизоды и проверенный
   учебный контекст из Narma. Патч и события нельзя подставлять из памяти модели.
2. Начать с текстового разбора фактов `.dem`. Эта проверка не оценивает просмотр
   видео и не заменяет существующий видеопроцессор.
3. Проверить контрольные ситуации, затем 30–50 эпизодов реальных демо, включая
   все позиции, разные задачи обучения, удачные решения и обычные эпизоды без
   заметных ошибок. Разделить набор на разработку и скрытую
   проверку; не подгонять промпт под ответы скрытого набора.
4. Сравнивать ответы вслепую по одному входу. Если сохранённых проверенных
   ответов ChatGPT нет, использовать тренерский эталон; такой результат не
   измеряет потери относительно Pro. Новые обращения к платному API не входят
   в текущие испытания.
5. Тренер оценивает соответствие фактам, герою и роли, пользу следующего действия,
   ясность и корректную неопределённость. Выдуманное событие, другой герой или
   безусловное требование фарма керри от саппорта — критическая ошибка.
   Рубрика и предварительные пороги описаны в `evals/open_coach/RUBRIC.md`.
6. После допуска измерить задержку и память при последовательных и параллельных
   запросах. Успешный ответ одному игроку не подтверждает обслуживание всех.

## Присоединение Hermes после допуска

[Hermes поддерживает собственный сервер модели](https://hermes-agent.nousresearch.com/docs/integrations/providers#custom--self-hosted-llm-providers)
через совместимый `/v1/chat/completions`. Это внутренний HTTP-интерфейс наших
вычислений; он не требует оплаты OpenAI за запросы.

Целевая цепочка: факты одного игрока → проверенный контекст обучения → модель →
проверка результата → сохранение разбора. Hermes сравнивает подтверждённые
эпизоды этого же клиента в нескольких матчах и предлагает изменение упражнения.

Для клиентского запуска ещё нужны отдельный провайдер в приватном брокере,
учёт попыток и ограничение параллельности, изоляция истории по клиентам,
проверка прав на каждый отчёт, отсутствие платных вспомогательных моделей и
общей памяти между клиентами. Существующий адаптер единственного владельца
`chatgpt_subscription` не превращается в эту схему переключением флага.

Ни production-провайдер, ни персональная авторизация, ни Hermes worker этим
пакетом не переключаются. Следующий этап зависит от исправления обнаруженных
ошибок качества, затем проверки на реальных отчётах и измерения ресурсов.
Покупка GPU не является предварительным условием этих CPU-испытаний.
